Cryptographic Blueprint

The 3-Pillar Anti-Agent Architecture

Engineered from ground up in pure Rust to render autonomous AST deobfuscators completely ineffective.

01 / POISON

Cryptographic Constant Entanglement

Every sensitive string, API endpoint, and number is pulled from the AST and encrypted into an AES-256-GCM constant pool. Each file derives an independent Content Encryption Key (CEK): HMAC-SHA256(root_key, "FILE:" + file_id). Root keys travel strictly inside offline Ed25519 license tokens.

const __SEC_POOL = "8f02a...c89"; // AES-256-GCM ciphertext
const apiKey = __SEC_DECRYPT__(0x14); // Fail-closed offline gate
02 / EXHAUST

Algorithmic Token Tarpit

Injects deeply recursive, syntactically authentic control-flow trees (up to 350+ KB). LLM agents attempting to traverse the call graph burn 200,000+ tokens until context overflow halts the attack.

function _0x8f2a(α, β, γ) { ... } // 48-tier cycle
03 / HALLUCINATE

Plausible Decoy Honeypots

Synthesizes realistic false authentication pathways and mock license APIs. Autonomous agents latch onto the decoys, producing confident yet totally fictitious vulnerability reports.

04 / ATTESTATION

Signed Artifact Manifests & CI Fingerprinting

Cryptographically seal your entire build tree with Ed25519 signed JSON manifests. Enforce byte-for-byte integrity and detect any supply-chain tampering or runtime modification in CI pipelines with --expect-fp pinning.
